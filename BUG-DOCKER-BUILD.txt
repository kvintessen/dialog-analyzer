Выполните эти команды сами в терминале (можно через ! в этом чате, если он поддерживает пароль sudo):

echo '{
  "mtu": 1376
}' | sudo tee /etc/docker/daemon.json
sudo systemctl restart docker

После этого напишите мне — и я перепроверю сборку docker compose build, чтобы подтвердить, что зависание исчезло.

Резюме диагностики, если хотите вставить в тикет/README:

- Симптом: docker compose build зависает на шаге RUN apk add ... && docker-php-ext-install ... в docker/php/Dockerfile.
- Причина: хостовая машина выходит в интернет через туннельный интерфейс amn0 с MTU 1376, а Docker-мост (docker0) использует MTU 1500 по умолчанию. 
Пакеты, превышающие 1376 байт, отправляемые из контейнеров, теряются в туннеле (ICMP Fragmentation Needed, судя по всему, блокируется/не долетает), 
из-за чего TCP скатывается в затяжные ретрансмиты — маленькие запросos (DNS, TLS handshake) проходят быстро, 
а любая реальная загрузка данных (пакеты apk, скачивание composer/npm зависимостей) стопорится на десятки секунд/минуты.
